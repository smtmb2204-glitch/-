# Счётчик калорий

Простое веб-приложение в одном файле: вводите продукт и массу в граммах, а калории считаются автоматически и добавляются к дневной норме.

## Возможности

- База из ~115 продуктов и блюд домашней кухни (ккал на 100 г)
- Автоподстановка калорийности при вводе названия
- Свои продукты: если продукта нет в списке, введите калорийность вручную, и он сохранится
- Кольцо прогресса: сколько съедено и сколько осталось до нормы
- Настраиваемая дневная норма (по умолчанию 1800 ккал)
- Новый день начинается с нуля автоматически
- Светлая и тёмная тема (по системным настройкам)
- Данные хранятся в браузере (`localStorage`), без сервера и регистрации

## Запуск

Откройте `index.html` в браузере. Больше ничего не требуется.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите файлы из архива.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

## Как добавить продукты

В файле `index.html` найдите объект `FOODS` и добавьте строку вида:

```js
"Название продукта": 123,   // ккал на 100 г
```

Значения для блюд домашней кухни усреднённые: реальная калорийность зависит от рецепта.
